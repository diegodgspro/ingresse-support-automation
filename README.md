# ingresse-support-automation

Ferramentas de automação para analistas de suporte de nível 2 na plataforma de ingressos Ingresse. Este projeto contém scripts para monitoramento de serviços críticos, consultas a banco de dados, geração de relatórios de erros e monitoramento de picos de eventos.

## Estrutura

- `scripts/` Scripts de automação (Shell e Python).
- `data/` Exemplos de banco de dados e logs.
- `docs/` Documentação de arquitetura e runbooks.
- `requirements.txt` Dependências Python.

## Requisitos

- Python 3.x
- Bash shell
- sqlite3 (para dados de exemplo)

## Uso

Consulte a pasta `scripts` para executar cada script de automação. Veja os documentos em `docs/` para instruções detalhadas de arquitetura e runbooks.
